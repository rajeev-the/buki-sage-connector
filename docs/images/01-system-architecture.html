MODULE 1

Auth & Token Engine

sage/auth.ts & sage/authScript.ts
Interactive OAuth CLI (npm run sage:auth) Ephemeral HTTP callback server on port 3000, CSRF state verification, multi-business picker.
Proactive Token Refresh Mutex Renews token 60s before 300s expiry. refreshPromise mutex guarantees zero concurrent race conditions.
Atomic POSIX File Storage Atomic write (tmp ➔ rename) with 0o600 permissions to .data/sage-tokens.json.
Cloud Auto-Seeder Auto-seeds from SAGE_ACCESS_TOKEN & SAGE_REFRESH_TOKEN env vars on Render.
MODULE 2

Resilient API Client

sage/client.ts & raw/types.ts
Network Resilience & Timeouts Strict 10s AbortSignal.timeout(10_000) on all requests. 5xx retries with jittered exponential backoff.
HTTP 429 Rate Limiter Handler Inspects Retry-After response header and pauses execution cleanly before retry.
Transient 401 Auto-Recovery Catches expired tokens mid-flight, refreshes tokens once, and retries request automatically.
Generic Envelope Traversal listAll<T>() follows $next pagination URLs until stream completes.
MODULE 3

Normalization Engine

sage/normalize.ts
Absent-Not-Default Enforcer Guarantees missing fields remain undefined. Strictly never defaulted to "", 0, or null.
Net vs. VAT Tax Logic InvoiceLine.net receives pre-tax net_amount (true spend). Invoice.total & outstanding preserve gross cash debt.
Financial Invariants Paid/void invoices strictly set outstanding = 0. Clamps outstanding <= total.
4 Canonical Entity Mappers LedgerAccount, Party (Customer/Supplier/Both), Invoice (Sales/Purchase), BankTransaction.
MODULE 4

Provider Seam & Mock

sage/provider.ts & mock/sage/
SageFinanceProvider Orchestrator Implements health() (validates tokens & latency) and sync(options) with watermark incremental filtering.
Canonical Schema Validator Runs validateCanonicalFinance check before writing to store.
v3.1 High-Fidelity Mock Server Standalone mock server on port 4020 simulating pagination, multi-currency, and health checks.
Render Web Service Wrapper Exposes public /health and / answering HTTP 200 for deployment verification.

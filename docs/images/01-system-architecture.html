BUKI CORE CONNECTOR

Connector & Sync Engine

1. Resilience & Transport Layer
• OAuth Token Manager: Proactive refresh (60s buffer), atomic token storage (0600)
• Client Pipeline: 10s AbortSignal timeout, 429 Retry-After backoff, 5xx retries
• Pagination Engine: Auto-traverses $next envelopes
2. Pure Normalization & Invariants
• Absent-Not-Default Rule: Missing fields remain undefined (never "", 0, or null)
• Net vs VAT: Lines track pre-tax net expense; invoice tracks gross cash receivable
• Canonical Entities: LedgerAccount, Party, Invoice, BankTransaction
3. Diff & Storage Layer
• Watermark Tracking: updated_or_created_since
• Tri-State Diff: Calculates added, changed, removed
• Atomic Persistence: Safe temp file write & rename to .data/store.json
